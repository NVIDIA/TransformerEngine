Ecosystem and historical integrations
=======================================

Transformer Engine has also been adopted by community projects and integrated
through past collaborations. The projects below are included as ecosystem and
historical references; their presence here does not imply that the Transformer
Engine project actively maintains or validates each integration.

* `DeepSpeed <https://github.com/deepspeedai/DeepSpeed>`_ — NVIDIA and the
  DeepSpeed project have collaborated on Transformer Engine support in the past.
  This integration is not actively maintained by the Transformer Engine project.
* `MosaicML Composer <https://github.com/mosaicml/composer>`_ — includes
  community support for training with Transformer Engine precision.
* `GPT-NeoX <https://github.com/EleutherAI/gpt-neox>`_ — includes community
  integration code for Transformer Engine layers.
* `Hugging Face Nanotron <https://github.com/huggingface/nanotron>`_ — includes
  community FP8 integration code using Transformer Engine.
* `Levanter <https://github.com/marin-community/levanter>`_ — includes community
  integration with the Transformer Engine JAX API.

For currently highlighted integrations, see the `Integrations
<https://github.com/NVIDIA/TransformerEngine#integrations>`_ section in the
project README.
